# 《生化危机·生存人生》实现计划

## 基线与验收

以根目录 PRD v1.0 与技术设计 v1.0 为实现合同。用户已要求从文档构建可玩的完整章节；原设计文档中“尚未实现”是编写时状态，不限制本次施工。保留纯前端、原生脚本、离线、单机、六地点、D1/D2 十时段以及固定内容池范围。验收覆盖 M1-M3：两条主线可通关、3 支线与 3 同伴、4 类结局、战斗/制造/存档、内容引用校验、规则与路线自动测试、实际浏览器刷新恢复与窄屏操作。无仓库，不执行 Git 操作。

## 文件职责

- `prototype/index.html`, `styles.css`: 语义界面、桌面三栏/手机面板、焦点可见与缩放布局。
- `prototype/js/content.js`: 6 地点、24+独立事件节点、随机事件、物品、配方、敌人、伙伴、任务和结局文本。
- `prototype/js/rules.js`: 确定性 RNG、建角、命令分派、时间/任务/事件/战斗/物资/伙伴/结局规则和状态不变量。
- `prototype/js/storage.js`: 快照、槽位、备份、导入导出、存储探测和冲突检测。
- `prototype/js/ui.js`, `app.js`: 渲染、无障碍焦点、表单事件委托、状态提交和错误恢复。
- `prototype/tools/serve.cjs`, `validate.cjs`: 安全 localhost 静态服务器与内容引用静态校验。
- `prototype/tests/*.test.cjs`: Node 内置测试覆盖规则、存档、路线及验证器。
- `prototype/README.md`, `CHANGELOG.md`, `TEST-REPORT.md`: 运行、版本变化和真实验证证据。

## 顺序与检查

1. 搭文件骨架与文档，定义状态契约和内容 ID，验证器先测试再实现。
2. 规则：RNG、时间、建角、纯命令事务、事件/战斗/终局；先写边界测试，再实现。
3. 存储：版本化 envelope 与槽位、主档/备份恢复、导入验证、刷新恢复测试。
4. 内容：六地点、双路线固定资源、三支线、同伴、敌人、物品/配方、随机池及四个结局；固定种子走通关键路径。
5. UI：标题/建角/主界面/辅助页/战斗/结束面板，键盘/屏幕阅读与响应式样式。
6. 启动器/校验器/说明；运行内容、单测、路线测试，并在浏览器走真实关键路径、刷新读档及 320px 布局。
7. 填实际 Node/浏览器版本、未覆盖项、交付清单，核对文档准确性。

规则关键边界：d100 的 1/5/6/95/96/100；INF 24/25/49/50/74/75/99/100；满载/超载阈值、HP/SAN/STA 极限；跨午夜最后撤离；战斗中途刷新；奖励幂等、无效命令不改变状态/RNG/revision；损坏档与超版本导入拒绝。
