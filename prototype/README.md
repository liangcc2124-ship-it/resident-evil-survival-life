# 生化危机 · 生存人生

浣熊市外围撤离章节的离线单机文字生存游戏。当前原型包含一条主线、两条撤离路线、三条支线、三名同行者、六地点和四类结局。

## 开始游戏

直接发给他人时使用项目 `release/生化危机-生存人生` 整个目录，或同名 ZIP。便携版已附 Node.js x64 和官方许可，收件人在 Windows x64 上解压后双击 `Start-Game.cmd` 即可，不需要另装 Node.js 或 PowerShell 7。存档属于浏览器，不随目录分发。源码目录的启动方式如下。

Windows 推荐双击 `Start-Game.cmd`，或桌面的“生化危机·生存人生”快捷方式。需要已安装 Node.js 和 PowerShell 7。启动器会在后台启动本机服务，确认首页可访问后打开浏览器；重复启动会复用现有服务。重启电脑后再次双击即可。服务仅绑定 `127.0.0.1:4173`。

可以直接打开 `index.html`。不同浏览器对 `file:` 来源的本地存储支持不一致；页面会实际检查存储能力，不支持时显示“仅本次有效”。

需要可靠的本机自动存档时，在本目录运行：

```text
node tools/serve.cjs
```

然后访问 `http://127.0.0.1:4173`。服务仅监听本机，只提供本目录静态文件，不包含业务接口。端口已被占用时请关闭旧服务后重试。运行时不需要安装 Node 或其他依赖；仅固定地址启动器需要 Node.js。编写和验证环境使用 Node.js `v24.19.0`。

## 核心规则

- 建角分为身份、能力和确认三步。姓名 1—20 字，年龄 18—65；普通市民、医护人员、维修工有不同技能和初始物资。
- 每日五个时段，D1/D2 共十个。移动进入地点事件并选择后只结算一个时段；读档可恢复待选事件和战斗回合。
- 撤离路线：在商业街取得路线便笺，再到警戒站换取通行证；或进入地下通道，使用工具/调查判定/承受擦伤拆闸等方式打通。两线都有不依赖随机骰点的解法。
- 想完成救援结局，需要先在诊所邀请周医生，或在警戒站邀请陈峻同行；也可独自撤离。
- HP 为零死亡，INF 到 100 转化。跨日消耗食物和饮水。永久死亡只锁定本局，不会删除其他槽。
- 自动槽每次完整行动保存；存档管理提供三个手动槽、JSON 导入/导出、结局图鉴。导入上限 2 MB，未知版本和非法状态会被拒绝。

完整参数与已实际执行的验收范围见同目录 `TEST-REPORT.md`。版本变更记录见 `CHANGELOG.md`。这里的游戏章节为原创幸存者故事，不自动改写正典事件。

```text

node --test tests/rules.test.cjs tests/storage.test.cjs tests/routes.test.cjs
```

上述测试命令仅供源码目录使用。发布 ZIP 不含测试夹具；只包含游戏运行文件、静态服务、内容校验器和使用说明。

项目不使用第三方运行依赖、CDN、账户、服务端业务接口、分析脚本或原作图像/音频资源。
